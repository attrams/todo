# Todo
This is an asp.net core web api project built to understand how to containerize asp.net core project.
This project is also available on docker hub at [attrams/todo](https://hub.docker.com/r/attrams/todo)

To run the project:
`docker run -p <your-port>:8080 attrams/todo`

Then navigate to http://localhost:your-port/weatherforecast
